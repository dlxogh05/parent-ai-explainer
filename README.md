# 부모님께 설명하는 AI

부모님이 ChatGPT를 왜·어떻게 쓰는지 같이 보는 **모노톤 HTML 발표**입니다.  
이미지는 전부 이 저장소 안에 있어, **로컬 폴더 없이도** GitHub Pages에서 그대로 동작합니다.

## 바로 보기

배포 후: `https://<user>.github.io/<repo>/`

로컬:

```bash
# 이 폴더에서
python -m http.server 8765
# http://127.0.0.1:8765/
```

조작: `←` `→` / Space · `N` 발표 메모 · `F` 전체화면 (전체화면에서 마우스를 멈추면 조작 막대가 숨어요)
